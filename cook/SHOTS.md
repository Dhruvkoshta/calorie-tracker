# Shots & Visual Targets

### S01: Desktop Dashboard Intake (1280x800)
- **Viewport:** 1280x800
- **Framing:** Full desktop layout with responsive 2-column or wide grid (`max-w-4xl` / `max-w-5xl`).
- **Focus:** Hero energy balance ring with high-contrast macro breakdown, staple presets, and today's meal timeline side by side.
- **Aesthetic:** Obsidian glass cards, subtle bevel highlights (`inset 0 1px 0 rgba(255,255,255,0.08)`), clean typography (`Outfit` / `Plus Jakarta Sans` with `JetBrains Mono` numbers).

### S02: Mobile Portrait View (390x844)
- **Viewport:** 390x844
- **Framing:** Mobile single-column stream, bottom-sticky or thumb-friendly segmented navigation, touch targets >= 44px.
- **Focus:** Quick logging ergonomics, date switcher, radial calorie remaining gauge, fast-tap staples.

### S03: Visual Food AI Scanner Tab
- **Framing:** Tab 2 (Photo AI)
- **Focus:** Sleek camera viewfinder HUD, glowing scan laser, instant food detection feedback badges, macro summary cards.

### S04: Intermittent Fasting Tab
- **Framing:** Tab 3 (Fasting)
- **Focus:** Glowing dual-arc circular timer, live hh:mm:ss ticker, tactile preset pills (16:8, 18:6, 20:4), milestone indicators.

### S05: Weight Progression Tab
- **Framing:** Tab 4 (Weight)
- **Focus:** Smooth cubic-bezier SVG weight progression chart with area gradient glow, trend statistics (Current, Change, Goal), weigh-in log stream.

### S06: Modal Dialogs (Meal, Weight, Settings)
- **Framing:** Active modal overlays
- **Focus:** Frosted backdrop blur, accessible ARIA dialog attributes, crisp input focus rings, one-tap save buttons with tactile feedback.
